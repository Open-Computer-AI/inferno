```text
AWS gateway -> AWS 127.0.0.1:19095 queue
            -> AWS 127.0.0.1:19085 SSH reverse listener
            -> Air 127.0.0.1:19085 helper

SSH transport: Air 100.70.23.11 -> Inferno 100.90.154.71:22
```

The Air tunnel LaunchAgent remains `com.opencomputer.inferno-attestation-aws-tunnel`. Its original durable key, reverse forward, retry supervision, keepalives and pinned known-hosts file are retained. AWS runs the official stable Tailscale package with DNS acceptance, route acceptance, exit-node use, Tailscale SSH and automatic netfilter management disabled. Node expiry is disabled on both AWS and the Air. The dedicated firewall unit and tailscaled dependency protect only the new `tailscale0` ingress: SSH from Air `100.70.23.11` and operator Mac `100.120.151.40` is allowed. The operator address intentionally retains administrative/rollback access. Other new tailnet ingress is dropped.

The actual gateway and cloudflared use host networking. Redis/Postgres Docker bindings are loopback-only. Existing Docker FORWARD rules were preserved. Other public security-group rules were preserved; only Air rule `sgr-0dc64ee0ab9876e39` was retired after the private production path passed validation.
