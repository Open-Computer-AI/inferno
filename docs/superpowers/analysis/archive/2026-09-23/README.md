# Archived reconciliation artifacts

These files are preserved historical evidence and tool inputs captured at
different upstream tips. They are **not** active status reports or unresolved
queues. The only live reconciliation decisions, current snapshot, verification
results, and remaining work are in `../../RECONCILIATION.md`.

`COMMIT-MANIFEST.md` and `port-coverage-missing.txt` remain read-only inputs to
the legacy frontend audit scripts; their rows are historical and do not define
current June completion. `upstream-watch.json` remains in the parent directory
because it is the incremental watcher watermark, not a feature ledger.
